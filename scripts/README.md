# Scripts & Automation 🛠️

This directory will store maintenance, validation, and generation scripts for the Viper Skills project.

---

## 🎯 Planned Scripts

- **`validate-skills`**: Lint frontmatter, verify markdown formatting, and check required sections across all 50 skills.
- **`build-catalog`**: Aggregate skill metadata into a single indexed JSON file (`catalog.json`) used by both the website and CLI.
- **`generate-bundle`**: Package skills into downloadable archives or distribution bundles.

---

## 🚧 Status

Scripts will be authored as skill schemas and requirements are formalized in the next phase.
